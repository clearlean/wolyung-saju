# 월영아씨 사주 소개팅

연고대 에브리타임 홍보를 염두에 둔 사주 기반 소개팅 MVP 프론트 프로토타입입니다.
현재 버전은 랜딩 → 스텝형 입력 → 사주 기반 연애운 풀이까지 동작하고, 신청서는 Cloudflare D1 에 저장됩니다. 실제 매칭과 사진 업로드, 결제는 아직 연결되어 있지 않습니다.

## 데모

- 공개 링크: https://wolyung-saju.clearlean01.chatgpt.site

## 실행

```bash
npm install
npm run dev
```

로컬 개발 서버는 기본적으로 `http://localhost:3000`에서 열립니다.

## 빌드

```bash
npm run build
```

## 현재 구현됨

- 모바일 중심 히어로 랜딩 화면
- `월영아씨 / 사주 소개팅` 카피 적용
- 이름, 생년월일, 태어난 시간, 성별, 인스타그램 아이디 입력 플로우 (5단계)
- URL hash 기반 스텝 전환, 뒤로가기 버튼, 전환 방향 애니메이션
- 입력값 검증 (실존하는 날짜인지, 시각 범위, 인스타그램 아이디 형식)
- 절기 기반 사주 계산 엔진 (연·월·일·시 네 기둥, 오행 분포, 십신, 신살)
- 사주 원국 표 — 오행별 색으로 칠한 여덟 글자와 오행 분포 막대
- 연애운 풀이 8가지 화두 (접이식, 화두당 4~5문단)
- `운명의 상대 찾기` 버튼 (접수 확인 상태까지)
- 신청서 Cloudflare D1 저장 (인스타그램 아이디 기준 업서트)
- 공개 Sites 배포

- 학교 선택 또는 학교 인증
- 관리자 확인/매칭 페이지
- 실제 매칭 로직과 매칭 결과 화면

- 개인정보 수집·이용 동의와 운영 정책 문구

## 사주 계산 방식

`lib/saju/` 안에 있습니다. 만세력 표를 들고 있지 않고 태양 위치를 직접 계산합니다.

- **연주** — 입춘(태양 황경 315°)에 바뀝니다. 양력 1월생과 입춘 전 2월생은 전년도 간지입니다.
- **월주** — 달력의 월이 아니라 절기로 나뉩니다. 출생 순간의 태양 황경을 30° 구간으로 끊어 월지를 정하고, 연간에 오호둔을 적용해 월간을 얻습니다.
- **일주** — 율리우스일 기반 60갑자입니다. 기준점은 2000-01-01 = 戊午일이고, 진태양시 자정에 바뀝니다.
- **시주** — 일간에 오자둔을 적용합니다. 23시~01시가 자시입니다.
- **시각 보정** — 한국 표준시가 UTC+8:30이던 구간과 역대 서머타임을 되돌린 뒤, 서울 경도(126.98°) 기준 진태양시 보정 −32분을 적용합니다. 균시차는 국내 만세력 관행에 맞춰 적용하지 않습니다.

태양 황경은 Meeus 『Astronomical Algorithms』 25장 저정밀 공식을 씁니다. 오차는 약 0.01°로, 절기 경계에서 ±15분 수준입니다. 절기가 바뀌는 순간에 15분 이내로 붙어 태어난 경우가 아니면 결과에 영향이 없습니다.

검증한 값 — 입춘 2025 (계산 02-03 23:07 / 한국천문연구원 23:10), 일주 2000-01-01 = 戊午, 2003-05-17 13:20 = 癸未 丁巳 庚寅 壬午.

## 데이터 저장

`.openai/hosting.json` 의 `"d1"` 값이 바인딩 이름이 됩니다. 현재 `"DB"` 로 켜 두었습니다.

- 스키마: `migrations/0001_create_submissions.sql`
- 로컬 개발에서는 API 라우트가 같은 스키마를 `CREATE TABLE IF NOT EXISTS` 로 만들어 두므로 따로 마이그레이션을 돌리지 않아도 됩니다.
- 배포 환경에는 `wrangler d1 migrations apply` 로 적용해야 합니다.
- 같은 인스타그램 아이디로 다시 제출하면 기존 행을 덮어씁니다.
- 나중에 매칭 쿼리를 바로 걸 수 있도록 원본 입력과 함께 계산된 네 기둥과 오행 분포도 같이 저장합니다.

## 주요 파일

- `app/page.tsx`: 화면 흐름, 입력 상태, 스텝 전환, 결과 화면
- `app/globals.css`: 화면 스타일, 배경 이미지 위치, 전환 애니메이션
- `app/api/submissions/route.ts`: 신청서 D1 저장 엔드포인트
- `lib/wolyung-flow.ts`: 카피, 스텝 정의, 타입, 에러 메시지
- `lib/saju/`: 사주 계산 엔진 (`constants` 간지표 / `astronomy` 태양 황경 / `korea-time` 표준시 보정 / `pillars` 네 기둥)
- `lib/love-reading.ts`: 연애운 8가지 화두의 문구 표와 조립 규칙
- `lib/submission.ts`: 폼 값 → 사주 입력 변환, 저장 요청
- `components/saju-chart-table.tsx`: 사주 원국 표
- `components/love-topics.tsx`: 접이식 화두 목록
- `public/astrology-woman.png`: 히어로/폼 배경 이미지

## 개발 인계 메모

문구를 고칠 때는 `lib/wolyung-flow.ts`(폼·화면 카피)와 `lib/love-reading.ts`(연애운 풀이)만 보면 됩니다. 연애운 풀이는 무작위 요소가 없어서 같은 사주면 언제나 같은 결과가 나옵니다. 나중에 모델 호출로 바꾸려면 `buildLoveReading` 의 시그니처를 유지한 채 내부만 갈아 끼우면 됩니다.

다음으로 붙일 일의 추천 순서입니다.

1. 개인정보 수집·이용 동의 화면 (지금은 동의 없이 저장하고 있습니다)
2. 학교/지역/사진 등 신청 항목 확정과 저장 스키마 확장
3. 관리자용 신청자 리스트 화면
4. 매칭 로직 — 저장해 둔 일주·오행 분포로 궁합 점수를 매기는 방식
5. 매칭 결과 화면과 인스타그램 아이디 공개 시점 정하기
6. 첫 매칭 무료, 추가 후보 보기 유료 여부 결정
7. 음력 → 양력 변환 테이블
