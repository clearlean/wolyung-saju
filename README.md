# 월영아씨 사주 소개팅

연고대 에브리타임 홍보를 염두에 둔 사주 기반 소개팅 MVP 프론트 프로토타입입니다.
현재 버전은 모바일 중심 랜딩과 스텝형 입력 플로우까지 구현되어 있으며, 실제 매칭/저장/업로드/결제 기능은 아직 연결되어 있지 않습니다.

## 데모

- 공개 링크: https://wolyung-saju.clearlean01.chatgpt.site

## 실행

```bash
npm install
npm run dev
```

로컬 개발 서버는 기본적으로 `http://localhost:3000`에서 열립니다.

## 빌드

```bash
npm run build
```

## 현재 구현됨

- 모바일 중심 히어로 랜딩 화면
- `월영아씨 / 사주 소개팅` 카피 적용
- 이름, 생년월일, 태어난 시간, 성별 입력 플로우
- URL hash 기반 스텝 전환
- 뒤로가기 버튼 및 전환 방향 애니메이션
- 입력값 기본 검증
- 로딩 화면과 입력 완료 화면
- 공개 Sites 배포

## 아직 미구현

- 입력 데이터 저장
- 사진 2장 업로드
- 학교 선택 또는 학교 인증
- 관리자 확인/매칭 페이지
- 실제 사주 기반 매칭 로직
- 매칭 결과 화면
- 추가 매칭 또는 리롤권 결제
- 개인정보 동의/운영 정책 문구

## 주요 파일

- `app/page.tsx`: 화면 흐름, 입력 상태, 스텝 전환 로직
- `app/globals.css`: 화면 스타일, 배경 이미지 위치, 전환 애니메이션
- `app/layout.tsx`: 사이트 메타데이터
- `lib/wolyung-flow.ts`: 카피, 스텝 정의, 타입, 에러 메시지
- `public/astrology-woman.png`: 히어로/폼 배경 이미지

## 개발 인계 메모

이 프로젝트는 현재 프론트 프로토타입입니다. 다음 개발자는 먼저 `lib/wolyung-flow.ts`에서 문구와 스텝 정의를 확인하고, `app/page.tsx`의 `BirthInfoForm`에서 데이터 수집 흐름을 이어 붙이면 됩니다.

실서비스로 확장할 때는 다음 순서를 추천합니다.

1. 신청자 데이터 저장 구조 설계
2. 학교/성별/지역/사진 등 필수 신청 항목 확정
3. 개인정보 동의와 운영 정책 추가
4. 관리자용 신청자 리스트 및 매칭 관리 화면 추가
5. 결과 티저와 실제 매칭 신청 CTA 분리
6. 첫 매칭 무료, 추가 후보 보기 유료 여부 결정
